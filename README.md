# Food Comp App

Aplicación móvil para la visualización de información asociada a una base de datos de composición de alimentos chilena.

---

> ⚠️ **Nota:** Actualmente, el funcionamiento de la aplicación se encuentra en pausa debido a una actualización mayor en el backend (API) y un proceso de refactorización integral de la app.

---

## Descripción

Food Comp App permite explorar y comparar información nutricional de alimentos de manera dinámica y personalizada. Las principales funciones incluyen:

- Búsqueda de alimentos mediante filtros avanzados o búsqueda sencilla por nombre.
- Visualización detallada de la información nutricional de cada alimento.
- Comparación entre diferentes alimentos para tomar mejores decisiones alimenticias.

- Interfaz moderna y fácil de usar.
